# Problem 22

```{ string s | s has 3k+1 number of 1's, where k >=0, or odd number of 1's }```

## NFA

![NFA #22](./n22.jpg)

Union of 2 sub-NFAs via `ε`: N1 accepts `3k + 1` 1's and N2 accepts an odd number of 1's. Either branch accepting means the whole NFA accepts.
